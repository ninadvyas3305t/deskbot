# 🤖 DeskBot

An AI-powered desktop companion robot built using the ESP32-S3.

---

## 🚀 Features

- 👀 Expressive OLED eyes
- 😊 Mood system
- 😴 Calm, Curious & Sleepy expressions
- ✨ Smooth eye movement
- 😉 Natural blinking
- 👁️ Double blink animation
- 🎲 Random behavior engine

---

## 🛠 Hardware

- ESP32-S3 DevKit
- 0.96" OLED SSD1306 Display
- TTP223 Touch Sensor *(Coming Soon)*
- INMP441 Microphone *(Coming Soon)*
- MAX98357A Speaker Amplifier *(Coming Soon)*

---

## 🖥 Software

- C++
- Arduino Framework
- PlatformIO
- Adafruit SSD1306
- Adafruit GFX
